# React Store Application

A learning React, TypeScript project that represents an online store with products such as phones, tablets, and accessories.
The app includes routing, product pages, favorites, and a shopping cart.

## 🌐 Preview

- [Live Demo](https://OleksandrY0.github.io/react-typescript-phonecatalog/)
- [Figma Design](https://www.figma.com/design/T5ttF21UnT6RRmCQQaZc6L/Phone-catalog--V2--Original?node-id=0-1&p=f)

## 🚀 Tech Stack
- **React**
- **TypeScript**
- **React Router v6 (HashRouter)**
- **Context API**
- **CSS / SCSS**
- **Vite**

## ✨ Key Features
- Home page with product overview
- Category pages:
  - Phones
  - Tablets
  - Accessories
- Product details page with dynamic routing
- Favorites functionality
- Shopping cart with add/remove logic
- Persistent global state using Context API
- 404 Not Found page
- Scroll-to-top on route change
- Responsive layout

## 🚀 Getting Started

### 1. Clone the repository:

```bash
git clone https://github.com/yourusername/react-typescript-phonecatalog.git
```

### 2. Install dependencies:

```bash
npm install
```

### 3. Start the development server:

```bash
npm run start
```

### 4. Open the project in your browser:

http://localhost:1234
